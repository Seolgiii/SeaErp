- 재고 이동: LOT 이동 신청 → 승인 → 새 입고관리/LOT 자동 생성 (보관처 변경) + 원본 LOT 차감
- 지출결의: 신청 → 승인 → 지출결의서 PDF (100만원 기준 ADMIN/MASTER 권한 분리)
- 결재 양방향: 승인 ↔ 반려 토글 시 재고 자동 복구 (soft delete — LOT 보존 + 재고수량=0)
