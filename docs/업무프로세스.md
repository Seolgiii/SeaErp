## 0. 사업 개요
- 업종: 수산물(주로 **냉동 생선**) 유통/도매 **+ 가공**. 수매 → 선별 → 가공(임가공) → 냉동 → 소분 → 판매/수출. ✓
  - **★ 핵심 정정(v0.2)**: 단순 유통이 아니라 **가공이 핵심 비중**. (자사 선별기 선별 → 외주 가공공장 → 재입고 → 소분 진공 → 판매). → 원가 모델을 "재고원가+부자재"가 아니라 **가공원가(제조원가)** 기준으로 봐야 함. (§3, §8)
- **수입(import)도 운영**: 사료·냉동 원물 수입 → 보통 부산 공장 선입고 → 제주 이동. ✓(v0.2)
- 운영: 1인 기획/개발 + 현장 작업자. 세일즈 담당 직원 있으나 **세일즈 파워 약함(특히 소매)**. 해외 영업 = 대표·사용자. ~
- **이전 시스템**: 씨오버(Seaover, 수산 전용 ERP) 사용 → SEAERP로 대체 중. 수산 전용인데도 **가공·원가 사슬·수율을 출고로 퉁쳐 정밀도 한계** → SEAERP가 메우는 핵심 차별점. ✓(v0.3)
- ❓ 주력 품목군(갈치·고등어·…)? 취급 규모(연 물량/매출)? 성수기·시즌성?

## 1. 가치사슬 (단계별)

### 1-A. 매입·수매
- **무엇**: 매입처 매입 + **경매 수매**. "입고 시 매입" = 경매에서 수매한 경우를 가리킴(도착≈입고). 수매가 = 박스당 매입단가. ✓
- **수입**: 사료·냉동 원물을 해외에서 수입 → 부산 공장 선입고가 흔함. ✓(v0.2)
- ❓ 수입은 발주(계약/LC)·통관 단계가 별도 → **수입 원가(인보이스+운임+관세+통관)** 를 입고원가로 추적해야 하나? (§8-D)
- ❓ 매입처·수입 대금 지급 시점·방식(현금/외상)? 지금 미추적 — 필요한가?
- ❓ 선박명 = 어선? 운반선? 왜 기록(원산지 증빙·이력추적)?

### 1-B. 입고
- **무엇**: LOT 단위 재고 생성. 품목·규격·미수(사이즈)·원산지·보관처·수매가. 입고증 PDF(자사창고 끝점일 때). ✓
- **흐름**: 작업자 신청 → 관리자 승인 → LOT 확정. (PC: 관리자 직접 등록+즉시 승인) ✓
- LOT번호 = `YYMMDD-품목코드-규격-미수-일련번호`. ✓

### 1-C. 보관
- **무엇**: 냉동 보관. 보관비 **일일 누적**(냉장료×보관일수 + 입출고비 + 노조비 + 동결비) → 재고원가에 쌓임. ✓
- 보관처 3종: **자사창고 / 외부창고(임대) / 가공공장**. ✓
- **부산↔제주 2거점 물류**: 수입·냉동물은 부산 선입고 후 제주로 이동하는 흐름 존재. ✓(v0.2, §1-E)
- ❓ 외부창고 임대·보관료 정산 방식? 동결비·노조비가 구체적으로 뭔지(누구에게 왜)?

### 1-D. 가공 (원물 → 가공품) — **★ 핵심 단계 (모델 확정 2026-06-30, B)**
큰 그림: **자사 선별기 선별 → 외주 가공공장(타사) 입고 → 가공·동결 → 자사 재입고 → 소분(진공) → 판매**.

**필렛 2종 (핵심 개념 — 꼭 기억):**
| 구분 | 가공지 | 흐름 | 임가공비 기준 |
|---|---|---|---|
| **ONE-Frozen** | 제주 내 | 원물 그대로 큰 통에 담아 가공공장 이동 → 바로 작업 후 **1회 동결** | 투입 kg당 |
| **TWO-Frozen** | 부산·해외 | 종이박스 냉동(1차) → 해동 → 가공(**가시제거** 등) → **재동결** → 수출 후 재수입 | 산출 kg당 |

**가공 모델 (확정 — 별도 거래):**
- **재고 이동과 형제지만 재사용 불가** — ① 수율로 "들어간 양 ≠ 나온 양"이라 이동 반려 가드(신규 LOT 재고수량==이동수량)가 깨짐 ② **N원물 → 1가공품**이라 이동의 1:1로 표현 불가.
- **입력 = N개 원물 LOT**(같은 규격/미수) + **투입 박스수**. **부분 투입 허용**(박스 단위) — TWO는 컨테이너 중량 맞추려 LOT 쪼개 넣음(①). 투입kg = 투입박스 × 원물 규격(원물은 규격 기반 정확). ONE은 통 수로 보냄 → 통↔LOT 묶음 단위 🅿️파킹(협의).
- **출력 = 1개 가공품 LOT**(품목구분=필렛). **한 배치 = 가공품 1종.** 부산물 없음(폐기, 가치 0). **산출 = 실측 총중량(kg) 직접 입력**(②) — 박스수에서 역산 X(가공품은 박스당 무게·피스가 가변, 가공해 봐야 앎). + 박스수(재고 단위) + 피스/미수(선택). 수율·가공원가 = 실측 산출kg 기준.
  - ⚙ 구현 함의: **가공품 LOT은 명목 규격이 아니라 실측 총중량을 보유**해야 정확(원물 LOT은 규격 기반 유지). LOT 무게 저장 방식 가공품용 보완 필요.
- **원가** = 가공원가 = (투입 원물 재고원가 합 + 임가공비) ÷ 산출kg → 가공품 LOT의 재고원가. (§3)
- **임가공비 입력** = **가공공장 단가 마스터**(보관처 비용 이력 패턴: 가공공장×품목/유형×ONE·TWO 기준×적용기간)에서 자동 적용 + 수동 보정. 지출결의 미연동(이중계상 방지). (E)
- **추적** = 가공품 LOT → 투입 원물 LOT들 링크(기존 '조상 LOT 체인' 확장 → 생애주기에서 원물까지 거슬러 보임).
- **가공 시차 = 2단계 '가공 중(재공품/WIP)'** [확정 2026-06-30, ③]: ㉠가공 투입(원물 차감 → 상태=가공 중) → (ONE 24h / TWO 1~2달) → ㉡가공 완료(가공품 LOT 입고·산출량·가공원가 확정). **ONE·TWO 공통**(혼합 안 함, 코드 한 갈래). 진행 물량이 '가공 중'으로 재고에 보임 → 장기 TWO 원물이 '재고 있음'으로 잘못 떠 오판/오판매되는 것 방지. **재공품(WIP) 재고 칸 신설.**
- **반려/취소** (④): 2단계라 자연스러움 — ㉠투입 취소 = 투입 원물 복구(가공품 아직 없음, 단순) / ㉡완료 후 취소 = 가공품 LOT 무효화 + 투입 원물 복구(가드: 가공품 미판매·미재가공 확인). 재고 이동 반려 복구 패턴 확장.
- **품목 인프라 이미 존재(B-3 확인)**: 품목마스터에 `품목구분`(원물/필렛/사료/종자) + 가공품 13종(갈치살 CTF·고등어필렛 MAF1·가시제거고등어 MAF4 등). 새 품목 생성 불필요, **연결만**. 품목구분으로 판매원가 2갈래(원물=재고원가/제품=가공원가) 자동 분기.
- 🅿️ **파킹**: ONE-Frozen 묶음 단위(한 통=1LOT vs 한 공장분=1LOT) — 비즈니스 협의 필요.
- ⚠ 정합성: 품목구분 일부 오분류(연어 필렛·명태포·명태민찌가 '원물') → 나중에 청소.

### 1-E. 재고 이동
- **무엇**: 보관처 간 이동 → 새 LOT 생성, 원본 차감. ✓(시스템)
- **왜**(v0.2): ① **가공 투입**(가장 큼) ② **수입품 물류**(부산 선입고 → 판매 위해 제주 이동, 특히 사료). ✓

### 1-F. 판매·출고  ← **시스템에서 가장 빈 부분**
- **무엇**: LOT 선택 → 판매처(자유텍스트)·판매가 입력 → 승인 → 재고 차감 + 출고시점 원가 스냅샷 + 출고증 PDF. ~
- **판매가 산정(v0.2)**: **원가 기반**. (제조)원가 파악 → 판매원가 계산 → 판매. **가격표 없음.** 수매가 시세에 크게 좌우돼 그때그때 변동. ✓ → **원가 계산 정확도 = 판매의 핵심**(사용자 강조)
- **주문 흐름(v0.2)**: 공식 주문/견적 시스템 없음. **건별 협상** — 바이어가 "이런 생선 생각 중" 연락 → 가격 제시 → 판매/수출. ✓
  - 채널: **해외 바이어 = 대표·사용자** / **국내 = 부산 계약직 지사장**(제주 국내판매는 거의 없음). 제주는 원물 임가공 위주. ✓
- **국내 vs 수출(v0.2)**: **국내 소비 비중 큼**. 수출은 **냉동물 위주**. 향후 가공품(소분 진공)을 해외로 확대 예정 → **포장 QR코드** 도입 동기. ✓
- **운임(v0.2)**: **자사 부담**(가공공장까지 운임도 자사). 수출은 대부분 **CIF**. ✓
- **판매 2모드**(→ §2): 소분(진공)=소포장 / 냉동물=벌크. ✓
- ❓ **단골·거래처(고객 마스터)** 필요? 바이어 반복 거래·건별 협상 이력 → 있으면 유용해 보임.

## 2. 판매 2모드 (원가 구성) — [메모리 sales-modes-cost]
| 모드 | 상황 | 판매원가 구성 |
|---|---|---|
| **소포장(소분·진공)** | 소량·고가, 가공품 | 가공원가 + 부자재(박스·아이스팩·내피·진공팩) + 운임 |
| **벌크/컨테이너(냉동물)** | 대량·저가 | 재고원가 + **운임(지배적, CIF)**, 부자재 ≈ 0 |
- 운임 = 변동(목적지·물량) → 부자재 마스터(고정 단가) 아님. 별도 변동 입력. 수출 CIF라 운임이 판매원가에 포함됨. ✓

## 3. 원가 모델 — [메모리 cost-terminology] ★ 2026-06-30 확정 (A 결정)
원물·제품 둘 다 취급을 반영한 **4단 사다리**:
- **재고원가** = 수매가 + 창고경비(냉장료·입출고비·노조비·동결비). *원물 보유 상태(미판매).*
- **가공원가** = (투입 원물의 재고원가 + 총임가공비) ÷ 산출kg. *제품(필렛) 보유 상태.*
  - 임가공비 기준: **ONE-Frozen = 투입kg당 / TWO-Frozen(부산·해외) = 산출kg당.** 둘 다 `총비용 ÷ 산출kg`로 동일하게 수렴.
  - 수율: 재료비에만 ÷수율 효과 = `총비용 ÷ 실제 산출량`. 실제 산출량 입력(수율 변동 5-2 → 입력 방식은 C).
  - 가공공장행 운임도 가공원가에 포함. (TWO-Frozen) 수입 관세·수입운임 부대비 추가 → D.
- **판매원가**:
  - ┌ 원물 판매 = 재고원가 + 운임·경비 *(벌크 모드)*
  - └ 제품 판매 = 가공원가 + 소포장·포장경비·운임 *(소포장 모드)*
- **매출원가(COGS)** = 판매원가 출고 시점 스냅샷(`출고시점 판매원가` 필드 — 코드·수식 불변, 라벨만).
- **용어 확정**: '제조원가'는 안 씀(정식 제조원가회계 기대 회피). **재고원가 → 가공원가 → 판매원가 → 매출원가** 4단어.
- **운임 단계 분리**: 가공공장행 → 가공원가 / 판매·수출(CIF) → 판매원가.

## 7. v0.2에서 확정된 핵심 통찰 (사용자 8문항 답변)
1. **이 회사는 "유통"이 아니라 "가공" 중심** — 선별→임가공→재입고→소분→판매. 원가 모델의 전제가 바뀜.
2. **필렛 2종(ONE/TWO-Frozen)** = 도메인 핵심 개념. TWO-Frozen은 수출→재수입까지 도는 국제 가공 흐름.
3. **판매는 원가 기반 건별 협상** — 가격표 없음, 시세 변동 큼 → **정확한 원가 계산이 판매의 생명줄**.
4. **수입 + 부산↔제주 2거점 물류** — 재고 이동의 주 이유(가공 투입 + 수입 물류).
5. **운임 자사 부담·수출 CIF** → 판매원가에 운임 필수 반영.
6. **영업 약함(특히 소매)** — 향후 시스템이 영업·견적을 보조할 여지.

## 8. 미결정 정리 (v0.2 — '원가 계산 화면' 설계 전제)
원가 계산 화면을 제대로 만들려면 아래 가공 관련 결정이 먼저다. 영향도 순:
- ~~A.~~ **[확정 2026-06-30]** 가공원가 모델·용어 채택 → §3. ('제조원가' 폐기, 4단 사다리, ONE=투입·TWO=산출 임가공 기준, 수율=총비용÷산출량, 운임 단계 분리.) **다음 = B.**
- ~~B.~~ **[확정 2026-06-30]** 가공 = 별도 거래(N원물→1가공품, 부산물 폐기), 품목구분(원물/필렛) 활용·추적 링크 → §1-D. **다음 = C(수율 입력).**
- ~~C.~~ **[확정 2026-06-30]** 수율 = 산출÷투입 **실측·계산만**(가정/표준수율 안 씀). 가공 거래에 투입kg·산출kg 기록 → 가공원가 = 총비용÷실산출kg. (품목 평균수율은 추후 *이상치 경고*용으로만.) **다음 = D.**
- ~~D.~~ **[확정 2026-06-30]** 수입 부대비(운임·관세·통관)는 사용자가 **외부에서 직접 계산해 단가에 포함** → 수매가로 기입. 시스템 **현행 유지**(별도 부대비 필드 불필요). 단점: 부대비 분해·감사 불가(추후 선택). **다음 = E.**
- ~~E.~~ **[확정 2026-06-30]** 임가공비 = **가공 거래에만** 기록(지출결의 미연동 → 이중계상 차단; 송금은 시스템 밖 관리). 단가는 **가공공장 단가 마스터에서 자동 적용**(보관처 비용 이력 패턴) + 수동 보정. 단가표 차원 = 가공공장 × 품목(가공유형) × ONE/TWO 기준(투입/산출) × 적용기간. **A~E 전부 확정 → '원가 계산 화면' 설계 가능.**
- F. 고객 마스터·미수금/미지급금 추적 여부(후순위).
