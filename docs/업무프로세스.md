# 업무 프로세스 (수산물 ERP) — v0.1

> 살아있는 문서. 사용자 확인·수정으로 채워나간다. 표기: **✓**=확인됨 / **~**=부분·추정 / **❓**=미확인(질문).
> 이 문서가 "정확히 무엇을 만들지"의 기준. 코드는 이걸 따라간다. (작성 2026-06-29, Claude 초안 — 사용자 정리 중)

---

## 0. 사업 개요
- 업종: 수산물(주로 **냉동 생선**) **유통/도매**. 수매 → 냉동 보관 → (선택적 가공) → 판매. **제조 아님.** ✓
- 운영: 1인 기획/개발 + 현장 작업자. ~
- ❓ 주력 품목군(갈치·고등어·…)? 취급 규모(연 물량/매출 대략)? 성수기·시즌성?

---

## 1. 가치사슬 (단계별)

### 1-A. 매입·수매
- **무엇**: 매입처에서 생선 매입. 선박명 기록. 수매가 = 박스당 매입단가. ✓(시스템 반영)
- ❓ 매입 결정/발주가 입고 **전에** 따로 있나, 아니면 물건 도착 = 입고인가?
- ❓ 매입처 대금 지급 시점·방식(현금/외상)? 지금 미추적 — 추적 필요한가?
- ❓ 선박명 = 어선? 운반선? 왜 기록하나(원산지 증빙·이력추적)?

### 1-B. 입고
- **무엇**: LOT 단위 재고 생성. 품목·규격·미수(사이즈)·원산지·보관처·수매가. 입고증 PDF(자사창고 끝점일 때). ✓
- **흐름**: 작업자 신청 → 관리자 승인 → LOT 확정. (PC: 관리자 직접 등록+즉시 승인) ✓
- LOT번호 = `YYMMDD-품목코드-규격-미수-일련번호`. ✓

### 1-C. 보관
- **무엇**: 냉동 보관. 보관비 **일일 누적**(냉장료×보관일수 + 입출고비 + 노조비 + 동결비) → 재고원가에 쌓임. ✓
- 보관처 3종: **자사창고 / 외부창고(임대) / 가공공장**. ✓
- ❓ 외부창고 임대·보관료 정산 방식? 동결비·노조비가 구체적으로 뭔지(누구에게 왜)?

### 1-D. 가공 (원물 → 가공품) — *큰 미확인*
- **무엇**: 원물 → 필렛 / 가시제거 / 진공팩(가공비). ~
- ❓ 가공하면 **품목이 바뀌나**(원물→필렛 = 다른 품목코드/LOT)? 지금 시스템은 가공을 별도 단계로 안 본다.
- ❓ **수율 손실**(가공 시 무게↓) 있나? 원가에 어떻게 반영?
- ❓ 자체 가공 vs 외주? 가공비 = 진공팩만인가, 노무·전기 등 더 있나?
- ❓ "가공공장으로 재고 이동" = 가공 투입을 뜻하나?

### 1-E. 재고 이동
- **무엇**: 보관처 간 이동 → 새 LOT 생성, 원본 차감. ✓(시스템)
- ❓ **왜** 옮기나 — 임대료 절감? 출하지 근처로? 가공 투입? 재고 통합?

### 1-F. 판매·출고  ← **시스템에서 가장 빈 부분**
- **무엇**: LOT 선택 → 판매처(자유텍스트)·판매가 입력 → 승인 → 재고 차감 + 출고시점 원가 스냅샷 + 출고증 PDF. ~
- **판매 2모드**(→ §2): 소포장(고가·소량 +부자재) / 벌크 컨테이너(저가·대량 +운임). ✓
- **시스템에 없음**: 고객 마스터·주문·견적·수출 개념·판매가 산정 근거. 판매처 = 텍스트뿐. ✓(확인)
- ❓ **판매가 어떻게 정하나** — 고객별 단가? 품목 시세? 건별 협상? 가격표 있나?
- ❓ **주문→출고 흐름** — 고객이 전화/메신저로 주문 → 누가 받아 출고 신청? 견적 단계 있나?
- ❓ **국내 vs 수출** 비중·차이(수출 시 통관·서류·운임)?
- ❓ **운임** 누가 부담(국내/수출)? FOB/CIF? 목적지·물량별 산정?
- ❓ 단골·거래처 관리 필요? (고객 마스터 신설?)

### 1-G. 정산·손익
- **무엇**: 지출결의(경비 지출). 손익 추이 = 매출−수매−지출 + 매출총이익(매칭 COGS). ~
- **의도적 비범위**: 분개·전표·부가세·세금계산서·결산 → 외부 회계 프로그램(더존·이카운트). ✓
- ❓ 고객 **미수금**(외상 매출) / 매입처 **미지급금** — 추적 필요? 지금 미반영.

## 2. 판매 2모드 (원가 구성) — [메모리 sales-modes-cost]
| 모드 | 상황 | 판매원가 구성 |
|---|---|---|
| **소포장** | 소량·고가 냉동 고급어 | 재고원가 + 부자재(박스·아이스팩·내피·진공팩) + 운임 |
| **벌크/컨테이너** | 대량·저가 | 재고원가 + **운임(지배적)**, 부자재 ≈ 0 |
- 운임 = 변동(목적지·물량) → 부자재 마스터(고정 단가) 아님. 별도 변동 입력.

## 3. 원가 모델 — [메모리 cost-terminology]
- **재고원가** = 수매가 + 누적 보관비(냉장료·입출고비·노조비·동결비). *재고 상태(미판매).*
- **판매원가** = 재고원가 + 부자재(소포장 시) + 운임.
- **매출원가** = 출고 시점 판매원가 스냅샷(`출고시점 판매원가` 필드).
- '제조원가'는 안 씀(유통업).

## 4. 역할·조직
- **WORKER**(현장·창고): 입고·출고·이동·지출 **신청**. ✓
- **ADMIN / MASTER**(사무·대표): 승인·마스터·원가·분석. 100만원↑ 즉시승인은 MASTER. ✓
- ❓ 실제 인원 구성? **영업 전담** 따로 있나, 대표 1인 다역?

## 5. 용어집 (혼동 방지)
- **미수** = 생선 **사이즈(마리수**, 예 "26미"). **외상/미수금 아님.** ✓ ← 중요
- **규격** = 박스당 kg. **LOT** = 재고 단위. **원산지** = 국내산/일본산 등.
- 재고원가·판매원가·매출원가 = §3.
- ❓ 다른 현장 은어/약어?

## 6. 시스템 범위 (현재)
- **있음**: 입고·출고·이동·지출·재고·LOT원가·보관비·결재·PDF·일일정산·분석(손익추이·매입통계)·마스터(품목·매입처·보관처·작업자·선박·부자재).
- **없음(앞으로 검토?)**: 고객 마스터·주문/견적·수출·운임·미수금/미지급금·가공 단계·판매가 산정·원가 계산 화면.
- **의도적 비범위**: 재무회계(분개·부가세·세금계산서·결산) → 외부 프로그램.

## 미결정 정리 (우선순위)
위 ❓ 들을 사용자 답변으로 채운다. 영향도 순:
1. **판매 앞단(1-F)** — 판매가 산정·주문 흐름·국내/수출·운임. (원가 계산 화면의 전제)
2. **가공(1-D)** — 품목 전환·수율·가공비 구성.
3. **재고 이동 이유(1-E)**.
4. **매입 앞단(1-A)** — 발주·지급.
5. **자금(1-G)** — 미수금/미지급금 추적 여부.
