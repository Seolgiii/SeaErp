# 안내 — PIN(4자리 비밀번호) 보호 기능

PIN을 여러 번 잘못 입력하시면 잠시 후에 다시 입력하시도록 안내됩니다.
내 계정을 보호하기 위한 안전 장치이며, 누구나 똑같이 적용되니 편하게 사용하시면 됩니다.

## 어떻게 동작하나요?

| 상황 | 다시 입력 가능 시점 |
|---|---|
| 5번 연속 틀린 경우 | **5분 후** |
| 5분 지난 뒤 또 5번 틀린 경우 | **30분 후** |
| 그 사이에 한 번이라도 맞게 입력하면 | 횟수가 0으로 초기화 |

## 사용 안내

1. PIN을 정확히 기억해 두세요. 메모장에 따로 적어두셔도 좋습니다.
2. 잊으셨다면 기다리지 마시고 관리자에게 바로 알려주세요. 관리자가 새 PIN을 알려드릴 수 있습니다.
3. 한 번이라도 맞게 입력하면 횟수가 초기화되니, 천천히 정확히 입력해 주세요.

## 자주 묻는 질문

**Q. 비밀번호를 잊었어요.**
A. 관리자에게 알려주시면 새 PIN을 알려드립니다. 본인이 직접 바꾸시는 화면은 따로 없습니다.

**Q. 다른 컴퓨터에서 시도해도 되나요?**
A. 같은 계정이라면 어느 기기에서나 똑같이 적용됩니다. 잠시 후에 다시 시도해 주세요.

**Q. 기다리는 동안 다른 일은 못 하나요?**
A. 본인 계정만 잠시 쉬는 상태가 됩니다. 다른 직원분은 평소처럼 로그인하실 수 있고, 본인도 시간이 지나면 다시 들어오실 수 있습니다.
