# 안내 — 출고·이동 신청 방법이 더 편해졌습니다

여러 LOT을 한 번에 출고·이동하실 때 **LOT마다 다른 판매처·판매가·보관처를 따로따로 적을 수 있게** 변경되었습니다.
이전에는 한 번에 같은 정보로만 신청할 수 있었는데, 이제는 각 LOT 사정에 맞게 다르게 입력하실 수 있습니다.

## 어떻게 동작하나요?

| 단계 | 동작 |
|---|---|
| 1단계 | **재고 조회**에서 출고하거나 이동할 LOT을 모두 골라 체크하세요 |
| 2단계 | 아래쪽 **출고 요청** 또는 **재고 이동** 버튼을 누르세요 |
| 3단계 | 새 화면(장바구니)에 고른 LOT이 위에서부터 차례로 나타납니다 |
| 4단계 | 첫 LOT 정보 입력이 끝나면 **다음 LOT으로 자동으로 넘어갑니다** |
| 5단계 | 모두 입력 후 **신청** 버튼을 누르시면 끝납니다 |

## 사용 안내

1. **LOT마다 판매처·판매가·보관처를 다르게 적으실 수 있습니다.** 예전처럼 한꺼번에 같게 적으셔도 되고, 다르게 적으셔도 됩니다.
2. 깜빡 잊고 추가하지 못한 LOT은 장바구니 화면 안에서 **검색하여 추가**하실 수 있습니다.
3. 잘못 담은 LOT은 위쪽 LOT 묶음 표시에서 **X**를 눌러 빼실 수 있습니다.
4. 수량을 입력하실 땐 박스 단위로 입력해 주세요. (예: 5박스 = "5")

## 자주 묻는 질문

**Q. 예전 방식이 더 익숙한데 그대로 써도 되나요?**
A. 네, 모든 LOT에 같은 판매처·판매가를 적으시면 예전 방식과 똑같이 처리됩니다. 다르게 적으셔도 되는 자유가 늘어난 것입니다.

**Q. 한 LOT만 신청할 때도 장바구니 화면이 나오나요?**
A. 네, 단일 LOT이어도 같은 화면에서 정보를 입력하시고 신청하시면 됩니다.

**Q. 신청한 뒤에 수량을 잘못 적은 걸 알았어요.**
A. 신청 내역 화면에서 해당 건을 취소하시고 다시 신청해 주세요. 자세한 내용은 "신청 결과 확인 방법" 안내문을 참고하세요.
