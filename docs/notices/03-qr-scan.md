# 안내 — QR 코드로 LOT 정보 바로 보기

출고증·입고증에 인쇄된 **QR 코드**를 카메라로 비추면 해당 LOT 정보 화면으로 바로 이동합니다.
LOT 번호를 직접 입력하지 않으셔도 되어 시간이 많이 절약됩니다.

## 어떻게 사용하나요?

| 단계 | 동작 |
|---|---|
| 1단계 | 시작 화면(첫 화면)에서 **QR 스캔** 버튼을 누릅니다 |
| 2단계 | 카메라가 켜지면 출고증·입고증의 QR을 화면 가운데에 맞춥니다 |
| 3단계 | 자동으로 인식되면 해당 LOT 상세 화면으로 이동합니다 |

## 사용 안내

1. **밝은 곳에서 사용해 주세요.** 카메라가 어두우면 인식이 늦어질 수 있습니다.
2. QR이 구겨지거나 젖었다면 잘 펴신 뒤 비춰주세요.
3. 카메라가 켜지지 않으면 휴대전화의 카메라 권한을 허용해 주세요. (설정 → 앱 권한)
4. 사용을 끝내신 뒤에는 화면 오른쪽 위 닫기(X) 버튼을 누르면 됩니다.

## 자주 묻는 질문

**Q. QR을 못 찾겠어요. 어디에 있나요?**
A. 출고증·입고증을 인쇄하시면 종이 위쪽에 정사각형 모양의 QR 코드가 함께 인쇄됩니다.

**Q. QR 없이 LOT 번호를 직접 입력해도 되나요?**
A. 네, 시작 화면의 **재고 조회**에서 LOT 번호로 검색하실 수 있습니다. QR 스캔은 더 빠르게 찾기 위한 방법입니다.

**Q. 카메라가 흐릿하게 보여요.**
A. 휴대전화 카메라 렌즈를 부드러운 천으로 닦아주세요. 그래도 안 되면 관리자에게 알려주세요.
