# 안내 — 신청 결과 확인 방법

입고·출고·이동·지출을 신청하시면 관리자가 검토하여 **승인** 또는 **반려**해 드립니다.
결과는 **신청 내역** 화면에서 한눈에 보실 수 있고, 따로 알림이 오지는 않으므로 가끔 들어가 확인해 주세요.

## 어떻게 확인하나요?

| 단계 | 동작 |
|---|---|
| 1단계 | 화면 아래쪽 **신청 내역** 메뉴를 누르세요 |
| 2단계 | 위쪽 탭에서 **전체 / 입출고 / 지출 / 완료** 중 보고 싶은 분류를 누르세요 |
| 3단계 | 각 신청 건마다 색깔로 상태가 표시됩니다 |

## 상태별 색깔 안내

| 색 | 상태 | 의미 |
|---|---|---|
| 🔵 파란색 | 승인 대기 | 관리자가 검토 중입니다 |
| 🟠 주황색 | 최종 승인 대기 | 100만원 이상 지출 등 추가 결재 중 |
| 🟢 초록색 | 승인 완료 | 처리가 끝났습니다 |
| ⚪ 회색 | 반려 | 승인되지 않았습니다 (사유는 카드를 눌러 확인) |
| 🔴 빨간색 | 취소 | 본인 또는 관리자가 취소한 신청입니다 |

## 사용 안내

1. **하루에 한 번 정도 신청 내역을 확인해 주세요.** 자동 알림이 따로 오지 않습니다.
2. **반려된 신청**은 카드를 한 번 누르시면 반려 사유가 보입니다. 사유를 보고 다시 신청해 주세요.
3. **승인 대기 중인 본인 신청**은 직접 취소하실 수 있습니다. 카드를 길게 누르거나 메뉴에서 취소를 선택해 주세요.
4. 입출고가 승인되면 출고증·입고증 PDF가 자동으로 만들어지며, 신청 내역 카드에서 바로 여실 수 있습니다.

## 자주 묻는 질문

**Q. 신청한 게 바로 처리되지 않아요.**
A. 관리자가 직접 확인하시는 절차이므로 잠시 시간이 필요할 수 있습니다. 급하실 경우 관리자에게 직접 말씀해 주세요.

**Q. 휴대전화 알림으로 결과를 받아볼 수는 없나요?**
A. 현재는 따로 알림 기능이 없습니다. 추후 추가될 예정이며, 그동안은 신청 내역 화면에서 확인 부탁드립니다.

**Q. 반려된 신청을 다시 살릴 수 있나요?**
A. 반려된 건은 되돌릴 수 없습니다. 사유를 확인하시고 새로 신청해 주세요.
