# 미해결 위험

지금 살아 있는 결함만 적는다. **해결되면 이 항목을 삭제한다** — 해결 경위는 `docs/journal.md`에
남기고 여기서는 지운다. 항목이 쌓이기만 하면 목록이 배경음이 된다.

항목 형식: 증상 / 위치 / 발견일.

---

## 1. 작업 정산 확정 시 LOT번호가 틀어진다 (최우선)

- **증상**: 규격 값이 미수 자리에 복사돼 저장된다. 확정 시 LOT번호가 `-24-24-`처럼 만들어진다
  (올바른 형태는 `-11-24-`).
- **런칭 전 반드시 수정한다.** 이대로 가면 첫 실재고부터 LOT번호가 틀어진다.
- **위치**: `app/admin/master/work-settlement/[id]/page.tsx:253` — `misu: r.spec || undefined`
- **발견일**: 2026-08-03

## 2. 품목마스터에 원물 '갈치'가 없다

- **증상**: 갈치 계열은 `선동갈치 CT1`·`선동알치 CT2`·`육동알치 CT3`·`갈치살 CTF`가 있는데
  원물 '갈치'만 없다. 품목코드를 정할 수 없어 갈치 입고분은 LOT번호를 만들지 못한다.
- **위치**: Airtable `품목마스터`
- **발견일**: 2026-04 최초 기록, 2026-08-04 재확인

## 3. 통(桶) 구분이 없어 원프로즌이 베이트小로 잘못 들어간다

- **증상**: 원프로즌은 통에 담아 운반하는데 생산내역 '구분'에 통이 없다. 지금은 베이트小로
  기록된다. 통 수량을 통 개수로 셀지 박스 환산으로 셀지도 미결이고, 이 값이 작업단가의
  분모라 전 품목 원가에 영향을 준다.
- **위치**: `lib/work-settlement-rates.ts:26` — `BoxType = "사료팬" | "베이트大" | "베이트小"`
- **발견일**: 2026-07-16

## 4. 동결비를 단일 컬럼으로 읽어 값이 null로 빠질 수 있다

- **증상**: 라이브 `보관처 비용 이력`의 동결비는 팬/베이트大/베이트小 3열로 나뉘어 있는데,
  보관처 비용 조회는 옛 단일 `동결비` 컬럼을 읽는다. 해당 보관처는 동결비가 null로 빠진다.
- **위치**: `lib/storage-cost.ts:83`·`:115` (단일 `SC.freezeFee` 참조).
  3열 매핑은 `lib/work-settlement-rates.ts:65-67`에 이미 있다.
- **발견일**: 2026-07-14

## 5. `buildLotNumber`가 세 곳에 복제돼 있다

- **증상**: LOT번호 조립 함수가 경로마다 따로 있다. 셋이 갈라지면 LOT번호 형식 규칙 자체가
  무의미해진다. 통합은 별도 작업으로 분리한다(지금 합치지 말 것).
- **위치**: `app/actions/inventory/inbound.ts:179` /
  `app/actions/admin/master-processing.ts:76` / `app/actions/admin/master-work-settlement.ts:117`
- **발견일**: 2026-08-04

## 6. DESIGN.md가 코드와 어긋난 적이 있고, 전체 감사는 하지 않았다

- **증상**: 공통 컴포넌트 강제 목록(§6-1)에 `NumCell`/`NumHead`가 빠져 있었고, 숫자 표기(§7-5)에
  포맷 함수의 실제 경로가 없었다. 두 건은 규칙을 CLAUDE.md에서 DESIGN.md로 옮기며 우연히
  드러난 것이고, **나머지 항목은 코드와 대조하지 않았다.** 다른 규칙도 실물과 다를 수 있다.
- **위치**: `DESIGN.md` (SEAERP 옵시디언 vault) 전체
- **발견일**: 2026-08-04

## 7. 폼 라벨 정렬이 미판정으로 남아 있다

- **증상**: 표의 입력칸 헤더는 우측 정렬로 확정했으나(DESIGN.md §7-6), 폼 라벨은 여전히
  중앙 정렬이고 근거 주석도 옛 전제("경계 상자 위 라벨은 중앙이 정석") 그대로다. 표 헤더와
  달리 폼 라벨은 실측하지 않았다.
- **위치**: `app/admin/master/_lot-table.tsx:15-16` — `labelClass`
- **발견일**: 2026-08-04
