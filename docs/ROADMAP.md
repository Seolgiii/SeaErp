### 최초 IA에서 정리된 항목 (중복·위치 재배치)
- '결재 이력·검색' → 거래 이력의 결재상태 필터로 흡수
- '일괄 처리 표' → 결재 수신함이 대기/완료 탭 + 다중선택 일괄을 모두 담당
- 'LOT 생애주기' → 메뉴 제외, 재고 조회 행 클릭 drill-down(`lot-timeline?lot=`)
- 'LOT별 누적 비용 분석' → 재고 조회 → LOT 상세 drill-down

- '운영 건강도 실시간' → `/health`가 이미 실시간 건강도 화면이라 제거

### 잔여 6항목 — 전부 "관측·이관" 성격
남은 것은 데이터 관리 화면이 아니라 **운영 관측(4) + 이관 채널(2)** 이다. 일상 관리 업무에는
당장 필요하지 않아 뒤로 밀려 있다.
- PDF 재발행 / 외부 ERP export
- 일일 보고서 화면(현재 이메일만) / INTEGRITY 로그 검색 / cron 실행 이력 / SCHEMA 동기화 상태

### 완료 기준 — **미충족**
- ❌ "Airtable UI 접근 불필요" — 아직 아니다. 2026-07-28에도 보관처 이름 정리 6건·구분 옵션 폐지를
  Airtable에서 직접 처리했다. **마스터 데이터 정리·스키마 변경은 여전히 Airtable UI/MCP 의존.**

## 현장 발생 트랙 (계획 밖에서 자란 기능)

중기·장기 목표에도, Phase 표에도 없었으나 **업무 요구로 만들어져 지금은 핵심이 된 것들.**
'앞으로 할 일'이 아니라 **'이미 만들어진 것'의 기록**이다 — 목표 목록과 성격이 달라 따로 둔다.

**이 목록의 쓸모**: 계획이 놓쳤는데 업무는 필요로 했던 게 무엇인지 패턴이 보인다. 지금까지는
**원가·정산의 실제 업무 절차**(A)와 **바이어 커뮤니케이션**(B)이 그 자리였다. 다음 계획을 세울 때
이 두 축을 먼저 살피면 계획 밖 발생을 줄일 수 있다.

### A. 원가·가공 모델 (2026-06-30 ~ 07-16)
- **원가 4단 사다리 확정** — 재고원가 → 가공원가 → 판매원가 → 매출원가 ('제조원가' 폐기)
- **가공 거래** — 2단계 WIP(투입 원물 차감 → 완료 가공품 LOT 생성 + 가공원가 롤업). 가공은
  입고·출고·이동과 나란한 **4번째 재고 사건(변환)**
- **작업 정산 등록** — 원물 매입을 사이즈별로 기록 → 확정 시 입고관리 + LOT 자동 생성.
  노임·동결비·입출고비·탈펜료 산출, 원프로즌 용도 자동 제외(이중계상 방지)
- 3단계 화주 배분 화면 — 프로토타입(저장/확정 미연결)
